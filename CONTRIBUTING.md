# Contributing labels

1. Pick a pseudonym, using lowercase letters, digits and hyphens. Don't use your real name unless you want to be credited with it.
2. Label documents with `label_tool.py`. Your work saves after each document to `labels/<pseudonym>.jsonl`, and you can stop and resume at any time.
3. Open a pull request that adds or updates only your own labels file.

Your file contains only document IDs, your answers and timestamps, never page text. By submitting it, you agree to release your labels under CC BY 4.0. A public pull request also shows your GitHub username.

Please label independently. Don't discuss specific documents with other annotators or look at their files first, because the point is to measure whether the written definitions alone produce agreement. Don't look at model labels first, either.

If a definition confuses you, open an issue describing the problem in general terms, without quoting page text or personal data.
